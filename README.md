# Botik ✨ — клавиатура-переводчик для Android

Клавиатура для Poco M5 (и любого Android 8+), которая переводит русский текст на другие языки
так, как написал бы носитель языка, прямо в любом приложении: Telegram, WhatsApp, почта, браузер.

## Возможности

- **Перевод уровня носителя бесплатно.** Кнопка «✨ Перевод» отправляет текст нейросети: без
  ключа через бесплатный публичный сервис, или через Gemini, DeepL, Claude со своим ключом. Модель переводит смысл, а не слова: идиомы и сленг заменяются живыми
  аналогами, сохраняются тон, эмодзи, ссылки и переносы строк, выбирается правильная форма
  обращения (tu/vous, du/Sie, вежливые формы в японском и корейском).
- **Быстро.** Перевод появляется по мере генерации (стриминг). Повторные фразы берутся из кэша
  мгновенно. Соединение с API переиспользуется и прогревается при открытии клавиатуры.
- **Мгновенный офлайн-черновик.** Пока вы печатаете, над клавиатурой появляется черновой перевод
  от ML Kit, который работает прямо на телефоне, без интернета. Нажмите на черновик, чтобы
  вставить его, или на «✨ Перевод», чтобы получить чистовой вариант.
- **29 языков**: английский, немецкий, французский, испанский, итальянский, португальский,
  украинский, белорусский, казахский, узбекский, турецкий, польский, чешский, нидерландский,
  шведский, финский, греческий, иврит, арабский, хинди, китайский, японский, корейский, тайский,
  вьетнамский, индонезийский, грузинский, армянский, азербайджанский.
- **Стиль**: «Как в оригинале», «Дружески» или «Официально».
- **Перевод выделенного фрагмента**: выделите часть текста, и переведётся только она.
- **Отмена**: кнопка ↶ возвращает исходный текст.
- **Эмодзи**: кнопка 😊 — около 1000 эмодзи по категориям и «недавние».
- **Буфер обмена**: кнопка 📋 — история скопированного (до 40 записей), закрепление 📌 долгим
  нажатием, кнопки «Выделить всё / Копировать / Вырезать / Вставить». Данные, которые приложения
  помечают как секретные (пароли из менеджеров паролей), не сохраняются.
- **6 тем**: Аметист, Океан, Закат, Мята, AMOLED (чёрная, экономит батарею), Светлая — или
  автоматически по системной теме.
- **Жесты**: свайп по пробелу двигает курсор, свайп влево с ⌫ удаляет слово, удержание пробела —
  выбор клавиатуры, удержание ⌫ ускоряет удаление.
- **Ряд цифр** над буквами (включается в настройках).
- **Удобная клавиатура**: ЙЦУКЕН и QWERTY, символы, ё и ъ на долгом нажатии, цифры на долгом
  нажатии верхнего ряда, автозаглавные буквы, двойной пробел ставит точку, свайп по пробелу
  двигает курсор, удержание ⌫ ускоряет удаление, быстрый набор двумя большими пальцами.
- **Внешний вид**: компактные клавиши с градиентами, всплывающие подсказки, клавиши «проседают»
  при нажатии, плавная анимация, настраиваемая высота клавиш, вибро- и звуковой отклик.
- **Производительность**: клавиши рисуются на одном Canvas без создания объектов во время набора,
  поэтому даже на Helio G99 в Poco M5 нет подтормаживаний. Релизная сборка ужата R8.

## Установка на Poco M5

### ⬇️ [Скачать botik-keyboard.apk](https://github.com/realskittels/botik/raw/claude/poco-m5-keyboard-translation-jz8ldf/botik-keyboard.apk)

Файл `botik-keyboard.apk` лежит прямо в корне репозитория и обновляется после каждой сборки.
Ещё одна копия — в [Releases](https://github.com/realskittels/botik/releases/latest).

1. Откройте ссылку выше на телефоне и скачайте APK.
2. Откройте файл. MIUI попросит разрешить установку из неизвестных источников для браузера
   или файлового менеджера — разрешите.
3. Откройте приложение **Botik Клавиатура** и пройдите шаги на экране:
   «Включить Botik в настройках» → «Выбрать Botik как клавиатуру».
4. Выберите сервис перевода (см. ниже). Режим «Бесплатно» работает сразу, без ключей.

> Новые версии обычно ставятся поверх старой. Если телефон пишет «конфликт пакетов»,
> удалите старую версию и установите новую. Чтобы так не было никогда, добавьте в Settings →
> Secrets репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` и `KEY_PASSWORD`.

## Как пользоваться

1. Пишите по-русски в любом поле ввода.
2. Нажмите на чип `RU → 🇬🇧 EN`, чтобы выбрать язык и стиль. Недавние языки показываются первыми.
3. Нажмите **✨ Перевод**: текст в поле заменится переводом. Кнопка ↶ вернёт оригинал,
   кнопка ■ остановит перевод.

Если отключить «Сразу заменять текст переводом», перевод появится в полосе над клавиатурой,
и вставить его можно нажатием.

## Сервисы перевода

Выбираются в приложении Botik → «Сервис перевода».

| Сервис | Ключ | Качество | Куда уходит текст |
|---|---|---|---|
| **Бесплатно** (по умолчанию) | не нужен | нейросеть, звучит естественно; запасной вариант — Google Переводчик | публичные сервисы Pollinations AI и Google, анонимно, без гарантий |
| **Google Gemini** | бесплатный, [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | нейросеть, уровень носителя | Google, по условиям Gemini API |
| **DeepL** | бесплатный «DeepL API Free», [deepl.com/pro-api](https://www.deepl.com/pro-api) | очень естественный для европейских языков | DeepL |
| **Claude** | платный, [console.anthropic.com](https://console.anthropic.com) | самый естественный | Anthropic |
| **Только офлайн** | не нужен | проще, чем у нейросетей | никуда, всё на телефоне |

Для нейросетей (бесплатный режим, Gemini, Claude) используется одна инструкция: переводить смысл,
а не слова, как написал бы носитель языка, сохраняя тон, эмодзи и форматирование.

Gemini и Claude в некоторых странах недоступны. Бесплатные публичные сервисы могут ограничивать
частоту запросов; если нейросеть не ответит, Botik автоматически переведёт через Google.

Для Claude можно выбрать модель: Opus 5.5 (по умолчанию, лучшее качество), Sonnet 5.5 или
Haiku 4.5 (самый быстрый). Запросы идут с `effort: low` для скорости, а для Opus и Sonnet включён
серверный fallback на случай ложного срабатывания фильтра безопасности.

## Приватность

- Текст уходит в интернет **только** по нажатию «✨ Перевод» и только в выбранный вами сервис.
  Офлайн-черновик при наборе считается на телефоне.
- В режиме «Бесплатно» текст получают анонимные публичные сервисы — не переводите так пароли,
  номера карт и другие секреты. Для приватности выберите «Только офлайн».
- В полях паролей и в числовых полях перевод отключён.
- Ключи хранятся только на телефоне. Клавиатура не сохраняет и не отправляет историю набора.

## Сборка из исходников

Нужны JDK 17 и Android SDK (API 35):

```bash
./gradlew testDebugUnitTest   # юнит-тесты
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

## Структура

```
app/src/main/java/com/botik/keyboard/
├── ime/
│   ├── BotikInputMethodService.kt  — сервис клавиатуры, полоса перевода, замена текста
│   ├── KeyboardView.kt             — отрисовка и обработка касаний
│   ├── KeyboardLayouts.kt          — раскладки RU / EN / символы
│   └── KeyboardTheme.kt            — цвета тем
├── translate/
│   ├── FreeTranslator.kt           — бесплатный режим: Pollinations AI + Google
│   ├── KeyedTranslators.kt         — Gemini и DeepL
│   ├── ClaudeTranslator.kt         — стриминговый перевод через Claude API (Java SDK)
│   ├── OfflineTranslator.kt        — офлайн-черновик через ML Kit
│   ├── TranslationEngine.kt        — потоки, отмена, кэш
│   ├── TranslationCache.kt
│   └── Languages.kt
├── settings/SettingsActivity.kt    — экран настройки
└── Prefs.kt
```
