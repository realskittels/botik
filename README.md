# Botik ✨ — клавиатура-переводчик для Android

Клавиатура для Poco M5 (и любого Android 8+), которая переводит русский текст на другие языки
так, как написал бы носитель языка, прямо в любом приложении: Telegram, WhatsApp, почта, браузер.

## Возможности

- **Перевод уровня носителя.** Кнопка «✨ Перевод» отправляет текст в Claude (по умолчанию
  Claude Opus 5.5). Модель переводит смысл, а не слова: идиомы и сленг заменяются живыми
  аналогами, сохраняются тон, эмодзи, ссылки и переносы строк, выбирается правильная форма
  обращения (tu/vous, du/Sie, вежливые формы в японском и корейском).
- **Быстро.** Перевод появляется по мере генерации (стриминг). Повторные фразы берутся из кэша
  мгновенно. Соединение с API переиспользуется и прогревается при открытии клавиатуры.
- **Мгновенный офлайн-черновик.** Пока вы печатаете, над клавиатурой появляется черновой перевод
  от ML Kit, который работает прямо на телефоне, без интернета. Нажмите на черновик, чтобы
  вставить его, или на «✨ Перевод», чтобы получить чистовой вариант.
- **29 языков**: английский, немецкий, французский, испанский, итальянский, португальский,
  украинский, белорусский, казахский, узбекский, турецкий, польский, чешский, нидерландский,
  шведский, финский, греческий, иврит, арабский, хинди, китайский, японский, корейский, тайский,
  вьетнамский, индонезийский, грузинский, армянский, азербайджанский.
- **Стиль**: «Как в оригинале», «Дружески» или «Официально».
- **Перевод выделенного фрагмента**: выделите часть текста, и переведётся только она.
- **Отмена**: кнопка ↶ возвращает исходный текст.
- **Удобная клавиатура**: ЙЦУКЕН и QWERTY, символы, ё и ъ на долгом нажатии, цифры на долгом
  нажатии верхнего ряда, автозаглавные буквы, двойной пробел ставит точку, свайп по пробелу
  двигает курсор, удержание ⌫ ускоряет удаление, быстрый набор двумя большими пальцами.
- **Внешний вид**: тёмная и светлая темы с градиентами, всплывающие подсказки клавиш, плавная
  анимация нажатий, настраиваемая высота клавиш, вибро- и звуковой отклик.
- **Производительность**: клавиши рисуются на одном Canvas без создания объектов во время набора,
  поэтому даже на Helio G99 в Poco M5 нет подтормаживаний. Релизная сборка ужата R8.

## Установка на Poco M5

1. Откройте вкладку **Actions** этого репозитория, выберите последний успешный запуск
   **Build APK** и скачайте артефакт `botik-keyboard-apk` (это zip с файлом `botik-keyboard.apk`).
2. Распакуйте архив на телефоне и откройте `botik-keyboard.apk`. MIUI попросит разрешить установку
   из неизвестных источников для файлового менеджера или браузера — разрешите.
3. Откройте приложение **Botik Клавиатура** и пройдите шаги на экране:
   - «Включить Botik в настройках» → включите переключатель напротив Botik;
   - «Выбрать Botik как клавиатуру».
4. Вставьте API-ключ Anthropic (его можно получить на [console.anthropic.com](https://console.anthropic.com)).
   Ключ хранится только в памяти приложения на телефоне.
5. По желанию нажмите «Скачать офлайн-модель», чтобы черновик работал сразу (около 30 МБ на язык).

> Без собственного ключа подписи каждая сборка в CI подписывается новым отладочным ключом,
> поэтому перед установкой новой версии старую нужно удалить. Чтобы обновления ставились поверх,
> добавьте в Settings → Secrets репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`
> и `KEY_PASSWORD`.

## Как пользоваться

1. Пишите по-русски в любом поле ввода.
2. Нажмите на чип `RU → 🇬🇧 EN`, чтобы выбрать язык и стиль. Недавние языки показываются первыми.
3. Нажмите **✨ Перевод**: текст в поле заменится переводом. Кнопка ↶ вернёт оригинал,
   кнопка ■ остановит перевод.

Если отключить «Сразу заменять текст переводом», перевод появится в полосе над клавиатурой,
и вставить его можно нажатием.

## Модели

| Модель | Когда выбирать |
|---|---|
| Claude Opus 5.5 (по умолчанию) | Самый естественный перевод |
| Claude Sonnet 5.5 | Немного быстрее и дешевле, качество очень высокое |
| Claude Haiku 4.5 | Самый быстрый и дешёвый |

Запросы идут с `effort: low`: для перевода не нужно долгое рассуждение, а ответ приходит
быстрее. Для Opus и Sonnet включён серверный fallback (`fallbacks: "default"`): если
классификатор безопасности по ошибке отклонит безобидное сообщение, запрос автоматически
повторится на другой модели.

## Приватность

- В Claude текст уходит **только** по нажатию «✨ Перевод». Офлайн-черновик считается
  на телефоне.
- В полях паролей и в числовых полях перевод отключён.
- Клавиатура не сохраняет и не отправляет историю набора.

## Сборка из исходников

Нужны JDK 17 и Android SDK (API 35):

```bash
./gradlew testDebugUnitTest   # юнит-тесты
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

## Структура

```
app/src/main/java/com/botik/keyboard/
├── ime/
│   ├── BotikInputMethodService.kt  — сервис клавиатуры, полоса перевода, замена текста
│   ├── KeyboardView.kt             — отрисовка и обработка касаний
│   ├── KeyboardLayouts.kt          — раскладки RU / EN / символы
│   └── KeyboardTheme.kt            — цвета тем
├── translate/
│   ├── ClaudeTranslator.kt         — стриминговый перевод через Claude API (Java SDK)
│   ├── OfflineTranslator.kt        — офлайн-черновик через ML Kit
│   ├── TranslationEngine.kt        — потоки, отмена, кэш
│   ├── TranslationCache.kt
│   └── Languages.kt
├── settings/SettingsActivity.kt    — экран настройки
└── Prefs.kt
```
